# Структуры данных и сортировки

Учебное задание к 16 числу. Язык: Python 3.12. Каждый алгоритм находится
в отдельном файле, каждый пункт ТЗ оформлен отдельным коммитом.

## 1. Репозиторий GitHub

Проект: https://github.com/maksimka66607/algoritm.

## 2. Структуры данных

| Структура | Файл | Операции |
|---|---|---|
| Динамический массив | `structures/array.py` | `append`, `pop`, чтение и запись по индексу, обход, длина |
| Односвязный список | `structures/linked_list.py` | `append`, `prepend`, удаление первого совпадения `remove`, обход, длина |
| Дек на двусвязном списке | `structures/deque.py` | `append`, `appendleft`, `pop`, `popleft`, обход, длина |
| АВЛ-дерево | `structures/avl_tree.py` | `insert`, `remove`, поиск через `in`, упорядоченный обход, длина |

Структуры реализованы самостоятельно. Массив использует буфер `ctypes`
и удваивает вместимость при заполнении. Индексы массива — от 0 до n−1;
отрицательные и выходящие за границы индексы вызывают `IndexError`.
Удаление из пустого массива или дека также вызывает `IndexError`.
Список при отсутствии удаляемого значения вызывает `ValueError`.
АВЛ-дерево хранит уникальные сравнимые ключи; повторная вставка игнорируется,
удаление отсутствующего ключа вызывает `KeyError`.

Сложность: доступ к массиву O(1), добавление в среднем амортизированно O(1);
добавление в начало/конец списка O(1), поиск для удаления O(n);
операции с концами дека O(1); поиск, вставка и удаление в АВЛ-дереве O(log n).

Существующая программа `zxc.py` (ограниченный кольцевой дек на NumPy)
и ее тесты сохранены. Интерактивный запуск: `python zxc.py`.

## 3. Сортировки

- `sorting/bubble_sort.py`: сортировка пузырьком, O(n²), лучший случай O(n).
- `sorting/quick_sort.py`: быстрая сортировка с трехчастным разбиением,
  в среднем O(n log n), худший случай O(n²). Явный стек вместо рекурсии.

Обе функции принимают итерируемые сравнимые значения, возвращают новый
отсортированный список и не изменяют исходный. Встроенные `sorted`/`sort`
в реализациях не используются. Пузырьковая сортировка стабильна.

```python
from structures.avl_tree import AVLTree
from sorting.quick_sort import quick_sort

tree = AVLTree()
for value in [30, 10, 20]:
    tree.insert(value)
print(list(tree))  # [10, 20, 30]
print(20 in tree)  # True
print(quick_sort([3, -1, 3, 0]))  # [-1, 0, 3, 3]
```

## 4. Тесты

Из корня репозитория:

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

Отдельные проверки:

```sh
python -m pytest tests/test_array.py -v
python -m pytest tests/test_linked_list.py -v
python -m pytest tests/test_linked_deque.py test_deque.py -v
python -m pytest tests/test_avl_tree.py -v
python -m pytest tests/test_sorting.py -v
```

Проверяются пустые структуры, граничные случаи, повторное использование,
дубликаты, случайные последовательности операций. Для АВЛ-дерева проверяются
все четыре типа поворотов, порядок ключей, высоты и баланс после вставок
и удалений. Сортировки сравниваются с эталоном `sorted`, дек — с
`collections.deque`. Случайные тесты используют фиксированный seed.
